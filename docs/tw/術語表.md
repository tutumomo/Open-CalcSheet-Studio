# 台灣版術語表

介面（`locales/zh-TW/`）與報告的用詞依此表。新增用詞時先查本表；表上沒有的，翻譯時選定後補進來。
英文欄是 `locales/en` 的原文用語（英文是介面文字的來源）。

## 用語原則

- 一律繁體中文、台灣用語、全形標點（，。：；！？「」（））。數字與英文單字旁不加空格。
- 避免中國用語：用「檔案」不用「文件」、「軟體」、「預設」、「資料」、「儲存」、「設定」、「列印」、
  「選單」、「視窗」、「游標」、「滑鼠」、「使用者」、「程式」、「網路」、「伺服器」、「介面」。
- 專有名詞、規範名稱、單位、變數名、檔名、按鍵名（Ctrl、Shift）、程式碼與 `{{插值}}` 保留原樣。
- 日期、數字：西元年；小數點用「.」，千分位用「,」。
